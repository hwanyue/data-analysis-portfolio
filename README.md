# data-analysis-portfolio

**目标岗位：数据分析师 · 方向：电商 **（在电商平台的拉新与投放场景里，我想解决“获客成本一直涨，却说不清该把预算投给哪类人群和渠道”的问题；具体做法是通过漏斗拆解、渠道归因和 LTV 分层，让预算优先流向高复购人群。）

## 目录结构

| 目录 | 内容 |
| --- | --- |
| `sql/` | 取数与指标计算的 SQL 查询 |
| `python/` | 数据清洗、分析脚本与 Notebook |
| `reports/` | 分析报告（Markdown / PDF / 图表） |
| `dashboards/` | 可视化看板（BI 配置、前端页面、截图） |

## 使用

```bash
git clone https://github.com/<hwanyue>/data-analysis-portfolio.git
```

各目录的用途与命名约定见目录内的 `README.md`。
